# AGENTS.md

## Назначение репозитория

Это Codex-native навык и плагин для арт-направления интерфейсов. Репозиторий не содержит прикладного веб-приложения. Основной продукт находится в `skills/better-art-direction/`.

## Обязательные правила

- В YAML-frontmatter `SKILL.md` оставлять только `name` и `description`.
- Имя каталога навыка и поле `name` должны совпадать: `better-art-direction`.
- Основной `SKILL.md` держать компактным; подробные правила размещать в `references/` и связывать прямыми относительными ссылками.
- Не превращать эвристики «анти-ИИ» в абсолютные запреты на конкретные шрифты, цвета, градиенты, карточки или стили.
- Не добавлять выдуманные метрики, отзывы, логотипы и возможности продукта в примеры.
- Скрипты должны работать без скрытых сетевых запросов. `static-audit.mjs` не имеет зависимостей; `visual-audit.mjs` использует Playwright и axe-core только из целевого проекта.
- Не добавлять обязательные MCP-серверы или hooks без отдельного обоснования и проверки безопасности.
- Все новые правила статического анализа должны иметь тест на срабатывание и тест на отсутствие очевидного ложного срабатывания.
- README вести на русском языке; команды должны быть копируемыми и соответствовать актуальным каталогам Codex `.agents/skills`.

## Проверка перед публикацией

```bash
npm ci
npm run check
npm run audit:self
```

Дополнительно проверить установщики в изолированном временном каталоге и выполнить `node --check` для всех `.mjs`-файлов.
