# Безопасность

Навык содержит два локальных помощника:

- `static-audit.mjs` только читает исходные файлы и формирует отчёт;
- `visual-audit.mjs` открывает URL, который явно передал пользователь, запускает локальный Chromium, делает снимки и сохраняет отчёт в указанную папку.

Скрипты не отправляют исходный код или результаты анализа во внешние сервисы. Браузерный аудит, естественно, выполняет сетевые запросы самой проверяемой страницы.

Не запускайте браузерный аудит против недоверенного URL с секретами в активной браузерной сессии. Помощник создаёт отдельный чистый контекст браузера, однако проверяемая страница остаётся исполняемым кодом.

О найденной уязвимости сообщайте через приватный канал владельца репозитория или GitHub Security Advisories. Не публикуйте эксплуатационные детали до исправления.
