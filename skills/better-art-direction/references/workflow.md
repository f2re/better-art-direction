# Detailed workflow

This reference expands the mode-specific process when the task is large or ambiguous.

## Direction

1. Inspect product evidence and classify the surface.
2. Define product truth, audience, task frequency, and stakes.
3. Identify domain materials: data, objects, instruments, documents, physical materials, language, and workflows.
4. Generate two or three structurally different candidates.
5. Score candidates and run the specificity test.
6. Select one signature and keep supporting choices restrained.
7. Map decisions into existing tokens and components.
8. Define responsive, state, accessibility, and performance constraints.
9. Produce an implementation map and verification plan.

## Audit

1. Freeze mutation: do not edit.
2. Inspect source and representative rendered states.
3. Run static and visual helpers when available.
4. Separate hard failures from heuristic template signals.
5. Consolidate repeated symptoms into systemic findings.
6. Record false positives and intentional conventions.
7. Return a verdict limited to inspected scope.

## Redesign

1. Establish preservation boundaries: routes, behavior, information architecture, content intent, and shared component ownership.
2. Capture a baseline.
3. Define and select the new direction.
4. State expected files to create, modify, and delete; obtain explicit approval before broad deletion.
5. Implement shared tokens and structural causes first.
6. Adapt representative screens before propagating the system.
7. Complete affected states and responsive variants.
8. Compare before and after in the browser.
9. Run tests and report remaining risks.

## Polish

1. Identify the existing direction and its strongest intentional decisions.
2. Do not replace the system.
3. Correct hierarchy, consistency, content fit, and over-decoration with the smallest systemic changes.
4. Preserve product density and task efficiency.
5. Verify all touched states and widths.

## Study

1. Identify whether the source is a screenshot, public URL, or owned design artifact.
2. Extract macrostructure, hierarchy, type roles, color roles, material language, and interaction patterns.
3. Separate universal principles from source-specific brand expression.
4. Do not reproduce trademarks, proprietary illustrations, paid templates, or pixel-identical layouts.
5. Translate the principles into the target product's mode and content.
6. Stop at diagnosis unless implementation is requested.
